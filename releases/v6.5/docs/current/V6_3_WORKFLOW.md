# v6.3 使用路径

## 批量抓取

进入“整表批量工作台”，先在 PDF Selection Workspace 选择来源模式。筛选条件只改变候选集；“全选当前筛选结果”才会加入已选集合。提交前的摘要展示 PDF 数、公司数、年份范围、表族和 Worker 数。

## 大型年报

优先建立文本索引，定位资产负债表、利润表或现金流量表，并提取“科目—附注编号”关系。附注定位只接受编号、科目和章节上下文的组合证据；不能以裸数字搜索替代。证据不足时使用 Direct Search 或进入人工复核。

## 金融投资表族

主表发现“债权投资（附注10）”等成员后，系统把它们作为并列 `member_table`，而非别名。研究层保留 `table_family=金融投资`、`member_table=债权投资`、`row_path` 和各观察维度；同名细项不会因名称相同而覆盖。

## 导出与备注

Long 数据是研究主数据；Wide 数据只做易读展示。`canonical_key` 和 `order_source` 留在审计层。表底注释保存在独立 Notes 表，并通过 Capture/表族/成员表/行路径关联，不重复写入每个数值单元。
