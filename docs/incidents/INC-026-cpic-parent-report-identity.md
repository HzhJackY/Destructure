# INC-026 — 中国太保上市母公司年报身份错配

状态：RESOLVED_FOR_INVESTMENT_PORTFOLIO

## 事实与处理

2024、2025 本地 PDF 已更新为上市母公司年报。原 `中国太保2023年报.pdf` 仍被外部进程
锁定并保持太保寿险披露，故新增不冲突的 `中国太保集团2023年年度报告.pdf` 作为上市
母公司 2023 正式证据，不做破坏性覆盖。

投资组合 Golden 使用独立 `CPIC_GROUP` 身份。三份母公司年报均为
`DIRECT_COMPOUND_TABLE`，物理页分别为 48、50、48，Stage A 3/3 MATCH，OCR 0。
