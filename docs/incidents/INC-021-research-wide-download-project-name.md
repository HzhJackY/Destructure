# INC-021 — 研究宽表下载名未体现合表项目名称

## 现象

合表项目已有面向用户的显示名称，例如
`太保金融投资 · 中国太保 · 2023–2025`，但研究宽表下载名仍固定为
`research_wide.xlsx` 或 `research_wide.csv`，离开系统后难以识别所属项目。

## 原因

下载按钮直接使用合表目录内稳定产物名，没有区分内部文件合同与用户下载展示名称。

## 修复

- 内部产物名继续保持 `research_wide.xlsx/.csv`，不影响刷新及程序消费。
- 用户下载名改为 `<合表项目显示名称>_研究宽表.xlsx/.csv`。
- 两个下载入口复用统一命名函数；显示名称缺失时回退到稳定 run ID。
- Windows 非法文件名字符替换为下划线，中文间隔点和年份连接线保留。

## 回归

研究宽表导出定向测试 9 项通过，未运行 PDF、Golden 或浏览器 E2E。
