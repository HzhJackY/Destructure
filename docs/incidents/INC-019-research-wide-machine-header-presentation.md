# INC-019 — 研究宽表暴露机器字段名且年份层级不清

## 现象

合表区下载的 `research_wide.xlsx` 已将 `member_table` 数据值映射为中文附注表名，
但左侧表头仍显示 `member_table / canonical_item / unit`；年报与数据年度虽采用两层
合并表头，但默认左对齐且没有明确的分组边界，用户难以快速识别归属关系。

## 根因

`write_presentation_wide_sheet` 直接把稳定机器列名写入 Excel，且只负责合并连续表头，
没有定义研究展示标签、对齐方式或年报组边界样式。

## 修复

- Excel 固定表头显示为 `附注表名 / 项目 / 单位`。
- 顶部 metadata 键使用中文展示名。
- 年报与数据年度居中；同一报告年度继续合并，并使用中等粗细边框标识组边界。
- 数据年度层在年度切换处同样使用中等竖线，但不延伸到数据区。
- `附注表名 / 项目 / 单位` 三个固定表头之间使用相同的中等竖线，保持左右分组一致。
- 下层数据年度的合并键包含全部父层，禁止相同数据年跨报告年度组视觉合并。
- 隐藏网格线、冻结左侧三列和表头、设置研究表常用列宽与金额格式。
- `research_wide.csv` 与 Canonical/Merge 机器字段保持不变。

## 追加：合计行加粗与年报式上边线（2026-08-06）

### 现象

研究宽表 Excel 中 `合计 / 小计` 等汇总行与明细行视觉权重相同，跨年度读取时
难以快速定位汇总关系；行顶边线方案反而会误导表分界，故改为浅色底纹。

### 修复

- 按 Canonical 语义 `row_type`（`TOTAL / IMPLICIT_TOTAL / SUBTOTAL`）识别合计类行，
  在 Excel 中加粗并使用浅色底纹突出汇总关系；识别不依赖中文“合计”文本猜测。
- 裁剪后的 `research_wide_trim` 不携带 `row_type`，行类型仅作为内存样式元数据传入
  `write_presentation_wide_sheet`，`research_wide.csv` 与 canonical 机器列不新增任何列。
- 合表项目内 `canonical_wide` 展示页与独立下载的 `research_wide.xlsx` 复用同一规则。

## 回归

- 验证中文表头、中文 metadata、年报合并区域、居中对齐、组边界线以及 CSV 机器合同。
- 合计类行加粗且有浅色底纹；`DETAIL` 行不加粗、无底纹。
