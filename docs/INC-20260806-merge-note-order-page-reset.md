# INC-20260806：合表附注号排序后页面上下文重置

## 现象

在合表详情的“结构顺序”页应用基准年份后，页面回到顶部和首个 Tab，用户误以为合表状态被清空。

## 根因

`refresh_merge_project` 完成后显式调用整页 `st.rerun()`。排序文件在当前执行轮的后续代码中本可直接重新读取，该重跑没有数据层必要；而 Streamlit Tab 与滚动位置未持久化，因此重跑丢失当前页面上下文。

## 修复

仅移除“应用基准年份并重新物化合表”成功路径中的 `st.rerun()`。保留重新物化调用、成功提示、当前 Merge Project、来源选择以及所有排序合同。

## 回归约束

该操作块必须调用 `refresh_merge_project`，且不得再调用整页 `st.rerun()`。

## 验证边界

按用户要求未执行测试或浏览器验证。
